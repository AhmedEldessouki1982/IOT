# Browser Captures

The `baseline-` files were captured from commit `f23229a`; the unprefixed
images show the completed redesign. Each set contains Home, Rooms, Scenes,
Security, Devices, Activity, and Settings at desktop (1440x900), tablet
(768x1024), and mobile (390x844), in dark and light themes.

`verification.json` and `baseline-verification.json` record measured target
sizes and horizontal overflow. The redesigned app had no target below 44x44px
at the tested viewports, no overflow at 390px, and no overflow at 360px in all
seven views and both themes. Baseline mobile target counts and overflow are
included for comparison.
